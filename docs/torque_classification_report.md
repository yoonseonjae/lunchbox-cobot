# 관절 토크 기반 그리퍼 페이로드 분류 알고리즘

**저자:** YOON  
**플랫폼:** Doosan DSR M0609  
**날짜:** 2026년 5월

---

## 1. 문제 정의

M0609 로봇이 메인반찬(돈까스)을 집는 동작(stage 3)에서, 집게만 잡은 경우와 집게+돈까스를 잡은 경우를 외부 센서 없이 구별해야 한다. 6축 외력 토크(`get_external_torque()`)만 사용한다.

판별 대상: **빈그리퍼 / 집게 / 집게+돈까스**  
수집 좌표: `main_dish_lift_l = [490.07, -370.31, 282.53, 120.47, -169.71, 31.29]`  
학습 데이터: 각 클래스 20샘플 (2개 자세 × 10샘플)

---

## 2. 핵심 문제

집게(40g)와 집게+돈까스(45g)는 **5g 차이**로, 6축 토크 원시값의 분포가 완전히 겹친다.  
→ 단순 거리 기반 분류 불가. **비선형 특징 확장 + LDA**로 분리 가능한 축을 찾아야 한다.

또한 같은 좌표라도 로봇 자세에 따라 토크 절댓값이 크게 달라진다 (J2: -3.x ↔ +5.x).  
→ 자세를 먼저 감지하고 자세별 기준값을 사용해야 한다.

---

## 3. 알고리즘

### 3-1. 자세 감지

```
J2 < 0  →  자세1 (기존 lift 좌표)
J2 > 0  →  자세2 (새 자세)
```

J2가 두 자세 사이에서 부호가 반전되어 완전히 분리됨. 이를 이용해 자세별로 독립적인 기준값 적용.

---

### 3-2. 1단계: 가중 최근접 중심 (빈그리퍼 vs 집게류)

**사용 이유**: 빈그리퍼와 집게류는 축별 분리도(σ 단위)가 충분히 크므로, 단순 거리 비교로 충분히 구분 가능. 단, 분리도가 높은 축(J2, J4)에 가중치를 집중해야 한다.

**공식**:

$$d(x, \mu_k) = \sqrt{\sum_{j=1}^{6} w_j \cdot (x_j - \mu_{k,j})^2}$$

- $\mu_k$: 클래스 $k$의 학습 데이터 평균 (자세별 별도 계산)
- $w_j$: 축별 가중치 `[J1, J2, J3, J4, J5, J6] = [0.1, 10.0, 2.0, 50.0, 1.0, 0.1]`

**축별 분리도 (자세2 기준)**:

| 축 | 빈그리퍼 vs 집게류 | 가중치 |
|----|----------------|------|
| J2 | 4.25σ | 10.0 |
| J4 | 4.09σ | 50.0 |
| J3 | 2.66σ | 2.0 |
| J1 | 0.38σ | 0.1 |

$d(x, \mu_\text{빈그리퍼}) < d(x, \mu_\text{집게류})$ 이면 → **빈그리퍼** 판정 후 종료.

---

### 3-3. 2단계: LDA + 비선형 특징 확장 (집게 vs 집게+돈까스)

**사용 이유**: 집게(40g)와 집게+돈까스(45g)는 원시 6차원에서 최대 분리도가 0.72σ로 선형 분리 불가. 비선형 특징 확장으로 차원을 높이면 LDA가 분리 가능한 방향벡터를 찾을 수 있다.

**특징 확장 (6차원 → 27차원)**:

$$\phi(x) = [\underbrace{x_1,\ldots,x_6}_{\text{원시}},\ \underbrace{x_1^2,\ldots,x_6^2}_{\text{제곱}},\ \underbrace{x_i x_j}_{i<j}]$$

**LDA 방향벡터 계산**:

$$\mathbf{w} = S_W^{-1}(\mu_+ - \mu_-)$$

- $S_W = \sum_{k}(X_k - \mu_k)^T(X_k - \mu_k) + \epsilon I$ : within-class scatter (정규화 $\epsilon=10^{-6}$)
- $\mu_+$: 집게+돈까스 클래스 평균, $\mu_-$: 집게 클래스 평균

**판정**:

$$s = \phi(x)^\top \mathbf{w}$$

$$s \geq \tau \Rightarrow \text{집게+돈까스}, \quad s < \tau \Rightarrow \text{집게}$$

$$\tau = \frac{\mu_{s,+} + \mu_{s,-}}{2} = -51.97$$

학습 데이터 기준 score 분포:

| 클래스 | mean score |
|--------|-----------|
| 집게 | -53.63 |
| 집게+돈까스 | -50.31 |

## 4. 전체 흐름

```
토크 측정 x ∈ ℝ⁶  (N샘플 평균)
        │
        ▼
  J2 부호 판별
  ┌──────────────────────┐
  J2 < 0: 자세1 기준값    J2 > 0: 자세2 기준값
  └──────────────────────┘
        │
        ▼
  [1단계] 가중 최근접 중심
  d(x, μ_빈그리퍼) vs d(x, μ_집게류)
        │
   빈그리퍼 ────────→ 종료
        │
   집게류
        │
        ▼
  [2단계] LDA (27차원)
  s = φ(x)ᵀw
        │
   s < -51.97 → 집게
   s ≥ -51.97 → 집게+돈까스
```
